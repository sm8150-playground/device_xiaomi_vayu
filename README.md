# Device Tree for POCO X3 Pro

This repo contains the device tree for the **POCO X3 Pro** (codename: `vayu` / `bhima`). This tree includes all necessary device-specific configurations to build LineageOS for the Snapdragon 860-powered POCO X3 Pro.

### Device Image
![POCO X3 Pro](https://wiki.lineageos.org/images/devices/vayu.png)

## 🧾 Device Specifications

| Feature          | Details                            |
|------------------|-------------------------------------|
| **Device Name**  | POCO X3 Pro                        |
| **Codename**     | vayu / bhima                       |
| **SoC**          | Qualcomm Snapdragon 860 (SM8150)   |
| **CPU**          | Octa-core Kryo 485                 |
| **GPU**          | Adreno 640                         |
| **RAM**          | 6/8 GB LPDDR4X                     |
| **Storage**      | 128/256 GB UFS 3.1                 |
| **Display**      | 6.67" IPS LCD, 120Hz, 1080x2400    |
| **Battery**      | 5160 mAh, 33W fast charging        |
| **Rear Camera**  | 48 MP (wide), 8 MP (ultrawide), 2 MP + 2 MP |
| **Launch Date**  | March 2021                         |
